# Diabetes Patient Readmission Analysis Using SQL

## Project Overview

This project analyzes the Diabetes 130-US Hospitals Dataset using SQLite and SQL to identify patterns in patient readmissions, medication usage, emergency visits, and demographic characteristics.

The goal is to demonstrate healthcare data analytics skills using SQL queries and real-world hospital data.

---

## Dataset

Dataset: Diabetes 130-US Hospitals for Years 1999–2008

Total Records Analyzed: 101,766

The dataset contains patient encounter information, demographics, hospital utilization metrics, medication information, and readmission status.

---

## Tools Used

- SQLite
- DB Browser for SQLite
- SQL
- GitHub

---

## Project Objectives

- Analyze patient readmission trends
- Examine age, gender, and race distributions
- Evaluate diabetes medication utilization
- Analyze emergency department usage
- Identify high-risk patient groups

---

## SQL Analyses Performed

### 1. Total Patients
Calculated the total number of patient encounters in the dataset.

### 2. Readmission Analysis
Analyzed the number of patients readmitted within 30 days, after 30 days, and not readmitted.

### 3. Readmission Percentage
Calculated the percentage of patients who were readmitted.

### 4. Age Distribution
Identified the most common patient age groups.

### 5. Gender Distribution
Analyzed patient encounters by gender.

### 6. Race Distribution
Evaluated racial demographics within the patient population.

### 7. Average Laboratory Procedures
Calculated the average number of lab procedures performed per patient.

### 8. Medication Usage
Analyzed diabetes medication utilization patterns.

### 9. Medication vs Readmission
Investigated the relationship between diabetes medication use and patient readmissions.

### 10. Emergency Visits Analysis
Evaluated emergency department utilization across different age groups.

### 11. Metformin Usage
Analyzed Metformin prescription patterns.

### 12. High-Risk Readmission Groups
Identified age groups with the highest readmission rates.

## Executive Dashboard Metrics

The following key performance indicators (KPIs) were generated using SQL:

- Total Patients
- Readmission Rate (%)
- Average Lab Procedures
- Average Medications per Patient
- Total Emergency Visits
- Diabetes Medication Users
- Most Readmitted Age Groups

---

## Key Findings

- Readmission trends were identified across multiple patient demographics.
- Older age groups accounted for a significant portion of hospital encounters.
- Diabetes medication usage was associated with differences in readmission patterns.
- Emergency department utilization varied across age groups.
- Healthcare resource utilization metrics were successfully analyzed using SQL.
